# Ajay Sharma — Frontend Portfolio

A modern React + Vite portfolio focused on frontend development, responsive UI and real-world web applications.

## Stack

- React
- JavaScript
- HTML5 / CSS3
- REST API / AJAX
- WordPress / ACF
- PHP / Laravel
- Git / Docker

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
